# Etsy Listing Generator 🛍️

AI-powered tool that generates SEO-optimized Etsy product listings from simple product information.

## What it does
- Enter your product name, category, and key details
- Get AI-generated title, description, and hashtags optimized for Etsy SEO
- Export everything as a PDF — ready to copy-paste into your Etsy store

## Live Demo
🔗 [Try it here](https://muun-etsy-tool.streamlit.app)

## Built With
- Python
- Streamlit
- OpenAI API
- PDF Export

## How to Run
1. Clone the repo
   git clone https://github.com/ismailardabaran/Etsy-Listing-Generator

2. Install dependencies
   pip install -r requirements.txt

3. Add your OpenAI API key
   Create a .env file: OPENAI_API_KEY=your_key_here

4. Run the app
   streamlit run app.py
